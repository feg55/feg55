## Selected projects

### [Astro Base](https://github.com/feg55/Astro-Base)

Interactive Solar System experience combining a **3D scene with an astrophotography platform**. Includes a static demo mode and a full-stack mode with authentication, photo uploads, administration tools and PostgreSQL-backed data.

`React 19` `TypeScript` `Three.js` `React Three Fiber` `Zustand` `FastAPI` `PostgreSQL` `Docker`

### [MCP Composer](https://github.com/feg55/MCP_Composer)

Visual tool for composing focused **MCP gateways** from multiple upstream servers and tools, with tool discovery, validation, aliases and permission policies.

`React` `TypeScript` `SCSS Modules` `Vite` `FastAPI` `MCP` `Docker`

### [QSwapp](https://github.com/feg55/QSwapp)

Privacy-friendly browser extension that fixes text typed using the wrong English or Russian keyboard layout, with automatic correction and configurable behavior.

`JavaScript` `Browser Extensions` `i18n` `Privacy-first`

### [YT-DW](https://github.com/feg55/YT-DW)

Desktop application for analyzing and managing authorized media downloads with editable metadata, persistent queues, background processing and native desktop UI.

`Python` `PySide6` `Qt` `yt-dlp` `FFmpeg` `PyInstaller`
